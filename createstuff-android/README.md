# CreateStuff - AI App Builder

An Android application that helps users build apps using AI-powered templates and code generation.

## Features

- **Project Templates**: Pre-built templates for various app categories
- **AI Code Generation**: Generate code with AI assistance
- **One-Click Deploy**: Deploy your apps instantly
- **Modern UI**: Material3 dark theme with smooth navigation

## Tech Stack

- Kotlin
- Jetpack Compose
- Material3 Design
- Navigation Compose
- MVVM Architecture

## Screens

- **Home**: Welcome screen with featured templates
- **Templates**: Browse all available templates
- **Create**: Start new project or use AI generation
- **Profile**: User stats and settings

## Permissions

- Internet access for AI generation
- Network state access

## Build

```gradle
./gradlew assembleDebug
```

## Requirements

- Android SDK 34
- Kotlin 1.9.10
- Min SDK 26 (Android 8.0)
